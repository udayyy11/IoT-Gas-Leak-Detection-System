**IoT-Based Safety Monitoring and Alert System for Chemical Factories**
📌 Overview

This project presents an IoT-based distributed safety monitoring system for detecting gas leaks in industrial environments. It uses ESP32-based sensor nodes, Bayesian probability, and Weighted Centroid Localization (WCL) to detect and locate gas leaks in real-time.

**Features**
Real-time gas leak detection 🚨
Bayesian-based probabilistic analysis
Leak localization using WCL algorithm
ESP-NOW wireless communication
Cloud integration (ThingSpeak + Blynk)
Web dashboard visualization
Multi-node distributed sensing
